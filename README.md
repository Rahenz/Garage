## Fitur
- Intro garage dengan pintu terbuka, mobil Skyline muncul, progress loading, tombol **Start Engine**, dan **Skip Intro**.
- Navigasi ke About, Hobbies, Playlist, Dream Garage, dan Contact.
- Kursor khusus bergambar setir BMW.
- Layout responsif untuk desktop dan ponsel.
- Ilustrasi Skyline R34, BMW M4, dan kategori hobi dalam format SVG.
- Video soundtrack opsional yang mulai setelah pengunjung menekan tombol Start Engine (bergantung koneksi internet dan ketersediaan YouTube).

## Menjalankan secara lokal
Cukup buka `index.html` di browser. Tidak membutuhkan instalasi package.

## Publikasi GitHub Pages
1. Buka repository **Settings → Pages**.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
4. Setelah deployment selesai, buka: https://rah enz.github.io/Garage/ (gunakan alamat tanpa spasi: https://rahenz.github.io/Garage/).

## Mengganti placeholder dengan foto pribadi
File SVG pada bagian profil dan hobi saat ini adalah placeholder ilustrasi, bukan foto pribadi asli. Untuk menampilkan foto milikmu:
1. Unggah foto JPG/PNG ke root repository.
2. Ubah atribut `src` pada `index.html` ke nama file foto tersebut.
3. Tempatkan foto sesuai kategori: profil, alam/traveling, konser, gaming, dan kuliner.

Foto asli yang pernah dikirim di percakapan belum tersedia sebagai berkas di repository ini, jadi aku tidak mengklaim foto-foto tersebut sudah terpasang.

Website ini merupakan proyek personal nonresmi dan tidak berafiliasi dengan merek kendaraan maupun waralaba film yang menjadi inspirasi visual.
