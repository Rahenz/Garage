# SYAHLA'S GARAGE — BLUE SPEED

Personal website Syahla Sabrina Nugraheni dengan tema baby-blue automotive / Fast & Furious inspired.

## Struktur folder

```text
syahla-personal-website/
├── README.md
├── index.html
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── images/
        ├── skyline-r34.svg
        ├── bmw-steering-wheel.svg
        ├── profile.svg
        ├── nature-beach.svg
        ├── nature-waterfall.svg
        ├── nature-mountain.svg
        ├── concert.svg
        ├── gaming-roblox.svg

```

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `syahla-personal-website`.
3. Buka `index.html` menggunakan browser.
4. Pertahankan struktur folder `assets` agar CSS, JavaScript, dan gambar terbaca.

Tidak memerlukan instalasi package atau server lokal.

## Teknologi
- HTML5 untuk struktur konten.
- CSS3 untuk layout, warna, animasi, responsivitas, dan cursor.
- JavaScript vanilla untuk intro garage, progress loading, tombol Start Engine, dan navigasi mobile.
- SVG untuk ilustrasi ringan.

## Mengganti placeholder dengan foto pribadi
Agar foto asli tampil, ganti file SVG placeholder pada `assets/images` dengan foto milikmu. Cara termudah:
1. Siapkan foto dengan format JPG/PNG.
2. Letakkan di `assets/images/`.
3. Ubah nilai `src` pada `index.html` sesuai nama file baru. Contoh: `assets/images/profile.svg` menjadi `assets/images/profile.jpg`.
4. Untuk galeri hobi, ganti `nature-beach.svg`, `concert.svg`, `gaming-roblox.svg`, dan `food-hunting.svg` dengan foto yang sesuai kategorinya.

**Catatan penting:** Foto-foto pribadi yang pernah dikirim di percakapan tidak berhasil diambil sebagai berkas pada proses pembuatan paket ini. Karena itu folder gambar memakai placeholder SVG yang bisa langsung diganti dengan foto asli; tidak ada foto pribadi yang diklaim sudah tertanam.

## Publikasi GitHub Pages
1. Buat repository GitHub.
2. Upload seluruh isi folder ini ke root repository.
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.
5. Tunggu GitHub menyelesaikan deployment dan buka URL Pages.
