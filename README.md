Website profil pribadi dengan tema automotive / Fast & Furious inspired dan palet baby blue, navy, serta putih.

## Fitur
- Intro garage dengan pintu terbuka, mobil Skyline muncul, progress loading, tombol **Start Engine**, dan **Skip Intro**.
- Navigasi ke About, Hobbies, Playlist, Dream Garage, dan Contact.
- Kursor khusus bergambar setir BMW pada perangkat desktop.
- Layout responsif untuk desktop dan ponsel.
- Ilustrasi Skyline R34, BMW M4, dan kategori hobi dalam format SVG.
- Audio/video soundtrack opsional yang mulai setelah pengunjung menekan tombol Start Engine (bergantung koneksi internet dan ketersediaan YouTube).

## Menjalankan secara lokal
Cukup buka `index.html` di browser. Tidak membutuhkan instalasi package.

## Publikasi GitHub Pages
1. Buka repository **Settings → Pages**.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
4. Tunggu proses deployment selesai. URL umumnya berbentuk `https://rah enz.github.io/Garage/` (tanpa spasi: `https://rah enz.github.io/Garage/`).

## Mengganti ilustrasi dengan foto pribadi
File SVG yang ada saat ini merupakan ilustrasi/placeholder, bukan foto pribadi asli. Untuk menampilkan foto sendiri:
1. Unggah foto JPG/PNG ke repository.
2. Ubah atribut `src` pada `index.html` ke nama file foto tersebut.
3. Untuk bagian hobi, tempatkan foto sesuai kategori: alam/traveling, konser, gaming, dan kuliner.
